# Recipient estimates and sent-mail history

Moving from Recipients to Content saves an audience-only draft and estimates active matches in its managed CleverReach filter. Blank subjects/bodies stay blank; an audience save preserves previously saved content. This does not create a mailing or send an email. Counts can also be refreshed explicitly. Defaults are a five-minute estimate cache and thirty-minute unused audience lease, configurable in Options.

Counts use validated `active_count` statistics, with no unverified subtraction of bounce/blocklist counters. Opt-outs and delivery exclusions can change. This is an estimate of active matches, not a promise of delivery. Simulation labels its fixed count explicitly. A failed read shows unavailable, never zero, and allows writing to continue. A failed or interrupted rule write stays protected as uncertain.

The audience fingerprint binds account, mode, list, suppression definition and exact compiled rules. Tag order is canonical. Minimum and maximum age are inclusive, including equal bounds. Date-derived rules are recomputed when checked; a date change that alters tested rules requires a fresh test. Rule read-back resolves CleverReach attribute IDs to their names. Before release, Intercom checks existing rules and reads fresh statistics without rewriting the approved audience. Zero blocks release, and a changed count requires renewed confirmation. Failed preflight does not become an uncertain send.

A durable mailing-attempt flag is set before provider preparation. Upgraded reservations are conservatively marked potentially mailing-associated, including those with no remote ID. Only a proved audience-only lease with no in-flight/uncertain operation can expire, be cancelled or deleted and return its filter to the pool. Active editing renews that lease locally. No remote filter is deleted; uncertain/submitted/scheduled mailings retain reconciliation safeguards.

Sent-mail content uses a dedicated Joomla `intercom.history` permission plus backend access. The dashboard lists up to five provider-confirmed live sends, ordered by their actual sending start time. Submitted, scheduled, uncertain, simulated and test-only messages are excluded. The separate Sent-mail history menu has pagination, date/type/actor/status filters and read-only detail pages. Audits remain in Audit history.

The exact authored HTML/plain text sent to CleverReach is frozen during preparation, together with bilingual preview renderings, sender, audience/rules and template version. A durable history intent precedes release. The history retains the preparation count and the final submission count separately. Provider-confirmed timestamps are recorded through reconciliation; completion does not establish inbox delivery. Opening history has no provider mutations or send actions. Sandboxed previews block scripts, resource/tracking loads and navigation.

Older records are explicitly reconstructed draft content, not exact historical renderings. Unknown send dates/counts are not invented. Already expired content is not retrieved from CleverReach. Configurable retention (default thirty days) purges full history snapshots alongside other local content copies; only operational metadata remains. Pending/scheduled/uncertain operations retain needed content. History is independent of board archive email configuration.

Automatic CI covers native install/update, incomplete drafts, body preservation, scope/revision checks, pool cap, expiry, read/write failures, delayed replies, count confirmation, durable/frozen history, pagination/order, permissions and retention. Real delivery exclusion and mixed-tag semantics still need production acceptance, along with the remaining items in recipient-estimates-production-plan.md.
